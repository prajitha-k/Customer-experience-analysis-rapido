# Customer-experience-analysis-rapido
Customer experience analysis of Rapido ride services using survey data collected through Google Forms. Analyzed customer preferences, satisfaction, ride behavior, and improvement areas using Excel and an interactive dashboard.
## Project Objectives
- Analyze customer experience and ride behaviour.
- Understand customers' preferred vehicle types and ride purposes.
- Analyze customers' preferred riding days.
- Identify commonly used payment methods.
- Analyze booking status distribution.
- Evaluate average ride ratings and customer loyalty.
- Identify major areas that require improvement.
- Present survey results through an interactive dashboard.
- Generate actionable insights that can help improve customer satisfaction.
## Data Collection

The dataset was created by conducting a Google Form survey to collect responses from Rapido users.

The survey collected information related to:

- Ride preferences
- Vehicle type
- Ride purpose
- Preferred days
- Payment method
- Booking status
- Customer ride rating
- Customer loyalty
- Waiting time
- Pricing
- Driver behaviour
- App-related issues
The collected Google Form responses were exported and prepared for analysis in Microsoft Excel.
